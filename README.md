# Тихий Клас — релізи

Готові APK застосунку **«Тихий Клас»** для проведення уроків в укриттях без інтернету.

## Завантажити

👉 **[Остання версія (APK)](https://github.com/TeacherUA-pixel/silent-shelter-releases/releases/latest)**

1. Відкрийте посилання на телефоні Android і завантажте файл `SilentShelter-…-release.apk`.
2. Дозвольте встановлення з браузера, якщо Android попросить.
3. Далі застосунок оновлюватиметься сам: коли телефон має інтернет, він покаже «Доступне оновлення».

> Якщо раніше була встановлена тестова (debug) версія — видаліть її один раз перед встановленням.

## Для розробників

Застосунок читає `releases/latest/download/version.json` і встановлює APK лише з https та зі збігом SHA-256.
Усі релізи підписані одним ключем.
